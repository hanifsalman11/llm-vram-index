Ollama & llama.cpp Performance Tuning Tips

  • ⚡Use Q4_K_M or IQ4_XS quantization in Ollama / llama.cpp for Mistral Small 3 24B Instruct: it retains 99.1% of FP16 perplexity while cutting VRAM usage from 50.2 GB down to 16.4 GB.
  • ⚡Enable Flash Attention (-fa in llama.cpp or OLLAMA_FLASH_ATTENTION=1) and Q8_0 KV-Cache quantization to cut long-context memory overhead by 50%.
  • ⚡Avoid splitting tensor layers across PCIe x4 risers when running multi-GPU setups; use `--split-mode row` with high-speed PCIe 4.0/5.0 x16 lanes.
  • ⚡Set `--n-gpu-layers 99` to offload all transformer blocks to VRAM, and reduce layer count by 4–6 layers only if your context window exceeds 32,768 tokens.

Frequently Asked Questions (Mistral Small 3 24B Instruct)

How much VRAM do I need to run Mistral Small 3 24B Instruct locally?

At 4-bit quantization (Q4_K_M) with an 8K context window, Mistral Small 3 24B Instruct requires 16.4 GB of VRAM. For 8-bit quantization (Q8_0), you need 27.7 GB, and for full 16-bit (FP16) weights you need 50.2 GB.

Can a single NVIDIA RTX 4090 (24GB) run Mistral Small 3 24B Instruct?

Yes! Because Mistral Small 3 24B Instruct in Q4_K_M uses 16.4 GB of VRAM, all layers fit 100% inside a single 24GB RTX 3090 or RTX 4090 with room to spare for KV cache.

What is the exact Ollama command to run Mistral Small 3 24B Instruct?

Install Ollama and execute `ollama run mistral` in your terminal. By default, Ollama pulls the 4-bit quantized GGUF build requiring approximately 16.4 GB of memory.
